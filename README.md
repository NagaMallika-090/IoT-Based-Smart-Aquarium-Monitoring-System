# IoT-Based Smart Aquarium Monitoring System

## 📌 Project Overview
This project is designed to monitor aquarium conditions using IoT and embedded systems technology. It helps maintain a healthy environment for aquatic life by tracking important parameters.

## 🚀 Features
- Temperature Monitoring
- Water Condition Monitoring
- Sensor-Based Automation
- Real-Time Data Observation

## 🛠 Technologies Used
- Embedded C
- IoT
- Sensors
- Microcontroller

## 📖 Project Objective
The main objective of this project is to automate aquarium monitoring and improve water quality management efficiently.
